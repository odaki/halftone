# Halftone for Pen Plotter

画像を CMYK（または K 単色）のハーフトーンに変換し、ペンプロッター用の **SVG / G-code** と、印刷原稿用の **PNG** を出力するブラウザアプリです。

単一の HTML ファイル（`index.html`）だけで動作します。サーバーもインストールも不要で、画像はブラウザの外に送信されません。

## 使い方

1. `index.html` をブラウザで開く
2. 画像（PNG / JPG / WebP）をドラッグ&ドロップ、またはクリックして選択
3. クロップ枠をドラッグ・ズームして処理範囲を決める
4. 設定を調整して **▶ 適用**
5. **⬇ PNG** / **⬇ SVG** / **⬇ G-code** でダウンロード

## 主な機能

### 出力モード
| モード | チャンネル | 用途 |
|---|---|---|
| CMYK カラー | C / M / Y（+ K） | カラーペン4本（または3本）で重ね描き |
| モノクロ | K | 黒ペン1本 |

- 高度な設定で K チャンネルの有無、GCR（グレー成分の K への置換率）、各チャンネルのスクリーン角度を調整できます
- C / M / Y / K ボタンで各チャンネルの表示・非表示を切り替えられます。ダウンロード時の状態が PNG・SVG・G-code に反映されます

### キャンバス
- 四角形または円形。サイズと余白は mm 単位
- 余白を負にすると、キャンバスの外側まではみ出して描画します（用紙より大きく描いて裁ち落とす用途）
- 背景色: 白 / クリーム

### ドット
- 形状: 円（アルキメデス螺旋で塗りつぶし）/ 正方形（ジグザグ走査で塗りつぶし）
- ペン線幅（0.1〜1.0 mm）、グリッド間隔、最大ドット半径比を調整できます
- 1ドット = 1本の連続したパスなので、ペンの上げ下げは1ドットにつき1回です

### 出力
| 形式 | 内容 |
|---|---|
| **SVG** | mm 単位。チャンネルごとに Inkscape のレイヤーとして出力。線は `stroke` のみ（塗りなし）なので、そのままプロッターソフトに渡せます |
| **G-code** | FluidNC / GRBL 向け。マルチカラー（1ファイル、色の切れ目で `M0` 停止してペン交換）またはチャンネル別（1色1ファイル）。原点位置、Y軸の向き、ペン上下（Z軸または任意コマンド）、送り速度を設定でき、設定はブラウザに保存されます |
| **PNG** | 384 DPI。T シャツなどグッズ印刷の原稿用。円形キャンバスでは円の外側が透明になります |

ファイル名は `halftone_{モード}_{日時}_{チャンネル}.{拡張子}` です（例: `halftone_cmyk_20260413143052_CMYK.svg`）。

## G-code について

- 単位 mm（`G21`）、絶対座標（`G90`）
- ペンの上下（Z 軸）と XY の移動は必ず別の行に出力します
- ドットはグリッドの行ごとに蛇行する順序で出力し、移動距離を抑えています
- 生成時に、ドット数・描画距離・移動距離・ペン上下回数・推定時間を表示します
- 実機に合わせて「ペンアップ Z」「Z 送り速度」などを調整してください。ペンの上下にかかる時間が全体の大半を占めることがあります

## 動作環境

モダンブラウザ（Chrome / Edge / Firefox / Safari）。大きなキャンバスでは PNG の生成にメモリを使います。Safari はキャンバスの大きさに上限があるため、約 270 mm 角を超えるサイズでは PNG を生成できないことがあります。
